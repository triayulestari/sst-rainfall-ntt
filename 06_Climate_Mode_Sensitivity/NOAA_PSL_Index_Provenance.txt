NOAA PSL INDEX PROVENANCE - STEP 06
==================================

PURPOSE
-------
Document the source series and limitations of the frozen index inputs
used for the SST-rainfall partial-correlation sensitivity analysis.

FIXED ANALYSIS INPUT
--------------------
File: climate_indices_input_2016_2025.csv
Columns: Year, Month, Nino34, DMI
Period: January 2016-December 2025 (120 months, no missing values)
Researcher-recorded initial download date: 12 September 2026.
The dated source file and its checksum were not provided with this folder
for independent verification of the original September 2026 snapshot.

SOURCE SERIES AND PRODUCT DISTINCTIONS
--------------------------------------
Nino 3.4 index:
  https://psl.noaa.gov/data/correlation/nina34.anom.data
  The online source's metadata, as inspected during this documentation
  revision, describe a NINA34 series (5N-5S, 170W-120W), ERSST V6,
  anomalies relative to 1981-2010, in degrees Celsius.
  Example cross-check: January 2016 = +2.13 (same as fixed input CSV).

  Do not substitute the separate NOAA PSL HadISST1.1-based Nino 3.4 series
  https://psl.noaa.gov/data/timeseries/month/Nino34/
  That distinct series reports January 2016 = +2.56.

Dipole Mode Index:
  https://psl.noaa.gov/data/timeseries/month/data/dmi.had.long.data
  https://psl.noaa.gov/data/timeseries/month/DMI/
  NOAA PSL describes the DMI as the anomaly SST gradient between western
  and southeastern equatorial Indian Ocean areas, based on HadISST1.1;
  unit: degrees Celsius.
  Example cross-check: January 2016 = +0.265 (same as input CSV).

REPRODUCTION AND CAVEATS
------------------------
The analysis uses the fixed CSV by default (a_prepare_climate_indices.m,
input_mode='snapshot_csv'). This prevents silent changes from future NOAA
updates. The alternate annual_txt input option requires local filenames
nina34.anom.data.txt and dmi.had.long.data.txt, which must be created by
saving/renaming the corresponding provider text files. A fresh download
may not reproduce the fixed snapshot if its historical values or index
version have changed.

The source identity checks above verify examples and current product
metadata, not all 120 original input months or the exact source-file
version at the historical download date. For a full archival audit,
retain the original downloaded annual text files with filenames,
creation/download dates, full URLs, file checksums, and a 120-value
comparison against climate_indices_input_2016_2025.csv.

This note does not imply causal interpretation or independent climate-mode
attribution. See README_06_Climate_Mode_Sensitivity.txt for the statistical
methods and sensitivity limitations.
