# Seasonal and Spatial SST–Rainfall Relationships over East Nusa Tenggara
This repository contains MATLAB scripts used to reproduce the principal analyses in:

"Satellite-Based Assessment of Seasonal and Spatial Sea Surface Temperature–Rainfall Relationships across the Tropical Drylands of East Nusa Tenggara"

## Software
MATLAB R2021a

## Study period
January 2016–December 2025

## Data
- Himawari-8/9 Level-3 SST: JAXA Himawari Monitor/P-Tree
- CHIRPS v3.0 monthly rainfall: Climate Hazards Center, UCSB

Raw datasets are not redistributed in this repository. Users should obtain them directly from the original data providers.

## Main analyses
1. Monthly climatology
2. Deseasonalized anomalies
3. Lagged SST–rainfall correlation
4. Seasonal correlation with permutation, FDR, and LOYO
5. Spatial correlation analysis
6. Niño 3.4 and DMI sensitivity analysis
7. SST-domain sensitivity analysis
